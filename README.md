# Backend Week 1 Project

This repository contains my foundational backend development work, focusing on server-side logic, APIs, and database integration.

## 🛠️ Technologies Used
- **JavaScript / Node.js**
- **Express.js**
- **MangoDB**

## ✨ What I Learned
- Setting up a basic backend server
- Creating RESTful API endpoints
- Handling HTTP requests and responses


## 🚀 How to Run
1. Clone the repo: `git clone https://github.com/Cantonia40/Backend-Week-1.git`
2. Install dependencies: `npm install`
3. Run the server: `node Intro.js`
